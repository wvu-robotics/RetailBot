GATHERING PACKAGES AND DEPENDENCIES:
http://wiki.ros.org/rosdep
http://wiki.ros.org/vcstool
--------------------
vcs import src < repos.yaml --recursive
rosdep install --from-paths src --ignore-src -r -y
sudo apt-get install ros-humble-joint-state-publisher
sudo apt-get install ros-humble-joint-state-publisher-gui

--------------------

VELODYNE PACKAGE:
https://wiki.ros.org/velodyne/Tutorials/Getting%20Started%20with%20the%20HDL-32E

NAV 2:
https://navigation.ros.org/getting_started/index.html

COLCON BUILDING:
--------------------
colcon build --continue-on-error

Note: If you are running on a virtual machine and it keeps crashing, add the '--executor sequential' tag


It may also be useful to run this line if your machine keeps crashing:

BUILDFLAGS=-j4 colcon build --parallel-workers 2
